# 自动小说生成器使用手册

## 简介

欢迎使用自动小说生成器！这是一个基于多智能体协作的全自动多轮交互式小说生成系统，能够帮助您从创意构思到完整小说内容的全流程创作。无论您是专业作家寻求灵感，还是小说爱好者想要尝试创作，本系统都能为您提供强大的AI辅助创作体验。

## 系统特点

- **多智能体协作**：由多个专业化智能体组成，各司其职，协同工作
- **全流程支持**：从创意概述、世界观构建、大纲设计、人物刻画到章节内容生成
- **多轮交互**：在创作过程中可随时调整方向，选择剧情分支
- **知识库支持**：内置知识库管理系统，提供丰富的创作素材
- **用户友好**：直观的Web界面，简单易用

## 使用流程

### 1. 创建项目

1. 访问系统首页：https://[deployed_frontend_url]
2. 点击"开始创作"按钮
3. 在项目页面点击"创建新项目"
4. 输入项目标题和描述（可选）
5. 点击"创建"按钮完成项目创建

### 2. 生成小说概述

1. 在新创建的项目中，系统会自动引导您进入概述生成页面
2. 输入您的创作灵感、想法或关键词
3. 选择要生成的概述数量（1-5个）
4. 点击"生成概述"按钮
5. 系统会生成多个不同的小说概述供您选择
6. 选择一个您喜欢的概述，点击"扩展"按钮获取更详细的情节梗概
7. 确认选择后，点击"继续下一步"

### 3. 生成世界观设定

1. 系统会基于您选择的小说概述，引导您进入世界观设定页面
2. 选择要生成的世界观设定数量
3. 点击"生成世界观设定"按钮
4. 系统会生成多套详细、自洽的世界观设定
5. 选择一个您喜欢的世界观设定
6. 点击"继续下一步"

### 4. 生成章节大纲

1. 系统会基于您选择的小说概述和世界观设定，引导您进入大纲生成页面
2. 设置章节数量和关键冲突元素（可选）
3. 点击"生成大纲"按钮
4. 系统会生成详细的章节大纲，包括总体故事结构和各章节详情
5. 选择一个您喜欢的大纲
6. 点击"继续下一步"

### 5. 生成人物设定

1. 系统会基于前面的选择，引导您进入人物设定页面
2. 选择要生成的人物设定集数量
3. 点击"生成人物设定"按钮
4. 系统会生成详细的人物设定，包括基本信息、背景故事、性格特质等
5. 选择一个您喜欢的人物设定集
6. 点击"继续下一步"

### 6. 生成章节内容

1. 系统会引导您进入章节生成页面
2. 选择写作风格
3. 点击"生成下一章"按钮
4. 系统会按照大纲逐章生成小说内容
5. 您可以点击已生成的章节查看详情
6. 在章节详情页，您可以：
   - 编辑章节内容
   - 润色章节内容
   - 生成剧情分支，选择不同的故事发展方向

### 7. 查看和管理项目

1. 在项目详情页，您可以查看项目进度和已生成的内容
2. 点击各个创作步骤可以返回相应页面进行修改或重新生成
3. 您可以随时编辑项目标题和描述
4. 所有生成的内容都会自动保存

## 高级功能

### 剧情分支

在章节详情页，您可以点击"生成剧情分支"按钮，系统会提供多个不同的剧情发展方向供您选择，让您的故事更加丰富多变。

### 内容润色

对于已生成的章节内容，您可以点击"润色"按钮，系统会优化文字表达，提升内容质量。

### 自定义编辑

所有生成的内容都支持手动编辑，您可以根据自己的想法对任何部分进行修改和调整。

## 常见问题

**Q: 生成内容需要多长时间？**
A: 根据内容复杂度不同，生成时间从几秒到几分钟不等。请耐心等待。

**Q: 我可以导出生成的小说吗？**
A: 目前系统支持在线阅读，导出功能将在后续版本中提供。

**Q: 如果我不满意生成的内容怎么办？**
A: 您可以随时点击"重新生成"按钮，或者手动编辑内容。

**Q: 系统会保存我的创作吗？**
A: 是的，所有项目和生成的内容都会自动保存在系统中。
