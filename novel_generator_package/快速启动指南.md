# 自动小说生成器 - 快速启动指南

## 一键启动脚本使用说明

本项目提供了三个便捷的Shell脚本，让您可以轻松管理小说生成器服务。

### 📁 脚本文件

- `start.sh` - 一键启动脚本
- `stop.sh` - 一键停止脚本  
- `status.sh` - 状态检查脚本

### 🚀 快速开始

#### 1. 一键启动服务

```bash
./start.sh
```

**功能说明：**
- 自动检查Python和Node.js环境
- 创建Python虚拟环境（如果不存在）
- 安装所有依赖包
- 检查并下载嵌入模型
- 初始化数据库
- 启动后端API服务（端口8002）
- 启动前端Web界面（端口3000）

#### 2. 检查服务状态

```bash
./status.sh
```

**功能说明：**
- 检查环境依赖是否满足
- 检查配置文件是否正确
- 检查前后端服务运行状态
- 检查端口占用情况
- 显示访问地址和操作提示

#### 3. 停止所有服务

```bash
./stop.sh
```

**功能说明：**
- 优雅停止后端和前端服务
- 强制终止占用端口的进程
- 清理临时文件和PID文件
- 显示停止后的状态

### 🔧 环境要求

**必需环境：**
- Python 3.8+
- Node.js 16+
- 足够的磁盘空间（用于下载嵌入模型）

**自动安装的依赖：**
- pnpm（如果未安装）
- Python虚拟环境
- 所有Python依赖包
- 所有Node.js依赖包
- sentence-transformers嵌入模型

### 📋 配置说明

启动脚本会自动检查并创建 `.env` 配置文件。

**重要配置项：**
```bash
# LLM配置
OPENAI_API_KEY=sk-dummy-key                    # API密钥
OPENAI_API_BASE=http://localhost:8321/v1       # API基础URL
DEFAULT_LLM_MODEL=gpt-4o-2024-08-06           # 模型名称

# 嵌入模型配置
DEFAULT_EMBEDDING_MODEL="/path/to/embedding/model"

# 服务端口
PORT=8002                                      # 后端端口
```

### 🌐 访问地址

启动成功后，您可以通过以下地址访问：

- **前端界面**: http://localhost:3000
- **后端API**: http://localhost:8002
- **API文档**: http://localhost:8002/docs

### 📊 日志文件

所有日志文件保存在 `logs/` 目录下：

- `logs/backend.log` - 后端服务日志
- `logs/frontend.log` - 前端服务日志

**查看实时日志：**
```bash
# 查看后端日志
tail -f logs/backend.log

# 查看前端日志
tail -f logs/frontend.log
```

### 🔍 故障排除

#### 常见问题

1. **端口被占用**
   ```bash
   # 脚本会自动处理，或手动终止进程
   lsof -ti:8002 | xargs kill -9
   lsof -ti:3000 | xargs kill -9
   ```

2. **Python环境问题**
   ```bash
   # 删除虚拟环境重新创建
   rm -rf venv
   ./start.sh
   ```

3. **Node.js依赖问题**
   ```bash
   # 清理并重新安装
   cd frontend
   rm -rf node_modules pnpm-lock.yaml
   cd ..
   ./start.sh
   ```

4. **嵌入模型下载失败**
   ```bash
   # 手动下载模型
   source venv/bin/activate
   python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('all-MiniLM-L6-v2')"
   ```

#### 检查服务状态

```bash
# 使用状态检查脚本
./status.sh

# 手动检查端口
netstat -tlnp | grep :8002
netstat -tlnp | grep :3000

# 检查进程
ps aux | grep "python.*run.py"
ps aux | grep "node.*vite"
```

### 💡 使用技巧

1. **首次启动**：首次运行可能需要较长时间下载依赖和模型
2. **重启服务**：如需重启，先运行 `./stop.sh` 再运行 `./start.sh`
3. **查看详细日志**：启动过程中的详细信息会保存在日志文件中
4. **配置修改**：修改 `.env` 文件后需要重启服务生效
